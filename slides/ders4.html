Yapı (Struct) Nedir? Neden İhtiyaç Duyarız?

Diziler sadece aynı türden verileri tutabilir (tümü int, tümü float gibi). Farklı türdeki verileri tek bir mantıksal varlık altında toplamak için struct kullanırız.

❌ Dağınık ve Karmaşık Değişkenler

string ogrAd = "Ahmet";
int ogrNo = 221045;
float ogrOrtalama = 3.42;

100 öğrenci olduğunda 300 ayrı değişken veya 3 ayrı dizi yönetmek imkansız hale gelir!

✔️ Tek Çatı: Struct (Veri Paketi)

struct Ogrenci {
 string ad;
 int no;
 float ortalama;
};
Artık kendi özel veri tipimizi oluşturduk!

💡 RAM Görünümü

Bir struct tanımlandığında, içindeki elemanlar RAM üzerinde birbirini takip eden bitişik bellek bloklarında tek bir paket halinde yerleşir.

Konu 1 / Slayt 2

Struct Tanımlama & Nokta (.) Operatörü

Struct bir kalıptır. Kalıptan nesne türettikten sonra alanlarına nokta (.) operatörü ile erişiriz.

struct_temel.cpp
#include <iostream>
using namespace std;

// 1. Yapı Tanımı (Kalıp oluşturma)
struct Ogrenci {
    string ad;
    int no;
    float gpa;
}; // <-- Noktalı virgülü UNUTMAYIN!

int main() {
    // 2. Değişken üretme ve değer atama (Nokta operatörü)
    Ogrenci ogr1;
    ogr1.ad = "Meliksah";
    ogr1.no = 101;
    ogr1.gpa = 3.75f;

    // Pratik ilk değer atama (Direct Initialization)
    Ogrenci ogr2 = { "Zeynep", 102, 3.90f };

    cout << ogr1.ad << " - No: " << ogr1.no << " - GPA: " << ogr1.gpa << endl;
    cout << ogr2.ad << " - No: " << ogr2.no << " - GPA: " << ogr2.gpa << endl;

    return 0;
}

İç İçe Yapılar (Nested Structs)

Bir struct'ın üyesi, daha önce tanımlanmış başka bir struct tipi olabilir. Tıpkı gerçek hayatta bir adresin il ve ilçe barındırması gibi.

nested_struct.cpp
struct Konum {
    int x;
    int y;
};

struct Rover {
    string model;
    int batarya;
    Konum koordinat; // İç içe yapı
};

int main() {
    Rover merakli;
    merakli.model = "Curiosity";
    merakli.batarya = 100;
    
    // Alt struct elemanına ardışık nokta (.) ile erişilir:
    merakli.koordinat.x = 12;
    merakli.koordinat.y = -4;

    cout << merakli.model << " Konumu: (" 
         << merakli.koordinat.x << ", " << merakli.koordinat.y << ")" << endl;

    return 0;
}

Yapı Dizileri (Array of Structs)

Birden fazla nesneyi yönetmek için struct tipinde bir dizi tanımlayabilir ve döngüyle kolayca listeleyebiliriz.

struct_dizisi.cpp
struct Urun {
    string ad;
    float fiyat;
};

int main() {
    // 3 elemanlı Urun dizisi
    Urun sepet[3] = {
        { "Direnç 10k", 1.5f },
        { "Kondansatör", 3.0f },
        { "STM32 Kartı", 250.0f }
    };

    cout << "--- SEPET LISTESI ---" << endl;
    for (int i = 0; i < 3; i++) {
        cout << i + 1 << ". " << sepet[i].ad 
             << " -> " << sepet[i].fiyat << " TL" << endl;
    }

    return 0;
}

İki Kritik Sembol: Nokta (.) vs Ok (->)

Geçen hafta gördüğümüz pointer mantığını struct'a uygularken C++ bize çok şık bir kısayol sunar.

📍

Nokta (.) Operatörü

Elinizdeki şey değişkenin doğrudan kendisi (nesne) ise kullanılır.

Ogrenci ogr;
ogr.ad = "Ali";
🎯

Ok (->) Operatörü

Elinizdeki şey bir bellek adresi (Pointer) ise kullanılır.

Ogrenci* ptr = &ogr;
ptr->ad = "Ali";
💡 Ok Operatörünün Matematiksel Eşiti

ptr->ad yazımı, aslında (*ptr).ad yazımının daha okunaklı ve estetik halidir. Önce adrese gider (dereference *), sonra o kutunun içindeki ad alanına erişir.

Konu 3 / Slayt 2

Hızlı Kod Örneği: Ok (->) Operatörü

Gömülü sistemler ve oyun motorlarında devasa yapıları taşımak yerine sadece adreslerini (pointer) gezdirir ve -> ile okuruz.

struct_pointer.cpp
struct SensorVerisi {
    int id;
    float sicaklik;
};

int main() {
    SensorVerisi s1 = { 1, 24.5f };

    // Struct pointer'ı oluşturup s1'in adresini veriyoruz
    SensorVerisi* sPtr = &s1;

    // Değeri pointer (ok operatörü) üzerinden güncelliyoruz:
    sPtr->sicaklik = 28.9f;

    // Orijinal nesne güncellendi mi?
    cout << "s1 Sicaklik: " << s1.sicaklik << endl; // 28.9 basar!

    return 0;
}

Yazılımda Devrim: Prosedürel vs. OOP

Bugüne kadar C tarzı Prosedürel (İşlemsel) kod yazdık. Peki modern dünyayı yöneten OOP (Nesne Yönelimli Programlama) felsefesi nedir?

📜 Prosedürel Programlama (C Yaklaşımı)

• Program bir tarif listesi gibidir (Adım 1, Adım 2, Adım 3).
• Veri ile o veriyi işleyen Fonksiyonlar birbirinden tamamen ayrı dünyalardadır.
• Proje büyüdükçe kimin hangi veriyi değiştirdiğini takip etmek zorlaşır.

🧱 Nesne Yönelimli Programlama (C++ Yaklaşımı)

• Program birbirleriyle konuşan canlı nesneler topluluğudur.
• Veri ve o veriye ait fonksiyonlar tek bir kapsülün içine konur.
• Kod güvenliği, yeniden kullanılabilirlik ve bakım çok kolaylaşır.

Gerçek Dünyayı Kodla Modellemek

Etrafınızdaki her şeyi iki temel soruyla yazılıma aktarabilirsiniz: "Neyi var?" ve "Ne yapabilir?"

5. Haftaya Köprü: Struct'tan Sınıfa (Class)

Gelecek hafta göreceğimiz Class dünyasına adım atarken aklınızda kalması gereken sır.

C++'ta Struct ile Class Arasındaki Tek Fark Nedir?

C++ dilinde struct ile class teknik olarak neredeyse ikiz kardeştir! İkisi de hem değişken hem fonksiyon tutabilir.

Aralarındaki tek fark Güvenlik Duvarıdır (Erişim Belirteci):

  • Struct: İçindeki her şey varsayılan olarak herkese açıktır (public). Herkes istediği gibi değiştirebilir.
  • Class: İçindeki her şey varsayılan olarak dışarıya kapalıdır (private). Veriyi korur, kapsüller (Encapsulation).
