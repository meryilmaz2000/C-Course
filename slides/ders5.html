Class Yapısı ve Erişim Belirleyiciler

Class, verileri (değişkenleri) ve o veriler üzerinde işlem yapan fonksiyonları (metotları) güvenli bir kapsül içinde birleştiren şablondur.

🔓 public

Herkese açıktır. main() içinden veya dışarıdaki herhangi bir koddan doğrudan erişilebilir.

🔒 private (Varsayılan)

Sadece sınıfın kendi fonksiyonları erişebilir. Dışarıdan nesne.degisken diyerek değiştirilemez.

🛡️ protected

Dış dünyaya kapalıdır (private gibidir), ancak bu sınıftan miras alan alt sınıflara (Derived Class) açıktır.

💡 Neden Veriyi Gizleriz (Encapsulation)?

Rover'ın bataryası public olsaydı, yanlışlıkla rover.batarya = -500; yazılabilirdi. Veriyi private yapıp kontrollü bir public fonksiyon üzerinden değiştiririz.

Sınıf Dışında Metot Yazımı: :: Operatörü

Sınıfın içini kalabalıklaştırmamak için fonksiyon imzalarını sınıf içinde bırakıp, gövdelerini dışarıda :: (Scope Resolution) ile yazarız.

main.cpp
TEK DOSYA DÜZENİ 
#include <iostream>
using namespace std;

class Rover {
private:
    int batarya;

public:
    string ad;

    // 1. Sınıf içinde sadece fonksiyon imzaları (prototipler) yer alır
    void bataryaAyarla(int yeniDeger);
    void durumYazdir();
};

// 2. Sınıf dışında '::' operatörü ile fonksiyon gövdeleri yazılır
void Rover::bataryaAyarla(int yeniDeger) {
    if (yeniDeger >= 0 && yeniDeger <= 100)
        batarya = yeniDeger;
    else
        cout << "Gecersiz batarya degeri!" << endl;
}

void Rover::durumYazdir() {
    cout << ad << " Batarya: %" << batarya << endl;
}

int main() {
    Rover r1;
    r1.ad = "Kasif-1";
    // r1.batarya = -50; --> DERLEME HATASI! private alana erişilemez.
    r1.bataryaAyarla(85);
    r1.durumYazdir();

    return 0;
}
🔍 :: (Scope Resolution / Kapsam Çözünürlük) Operatörü Nedir?

Rover::durumYazdir() ifadesi derleyiciye şunu söyler: "Bu fonksiyon Rover sınıfına aittir; dolayısıyla sınıfın private değişkenlerine erişme yetkisi vardır."

Nesnenin Yaşam Döngüsü: Constructor & Destructor

Bir nesne bellekte doğarken ve ölürken C++ tarafından otomatik olarak tetiklenen iki özel fonksiyon vardır.

👶 Constructor (Yapıcı / Kurucu Metot)

• Nesne oluşturulduğu anda otomatik çalışır.
• Sınıf ile birebir aynı isme sahiptir (Sensor::Sensor).
• Dönüş tipi (void bile) yoktur.
• Amacı: Değişkenlere güvenli ilk değerleri vermektir.

🧹 Destructor (Yıkıcı Metot)

• Nesnenin ömrü bittiğinde (fonksiyon/program sonlanırken) otomatik çalışır.
• Başına tilda (~) işareti konur: Sensor::~Sensor().
• Parametre almaz, dönüş tipi yoktur.
• Amacı: Ayrılan kaynakları/belleği temizlemektir.

Kod Örneği: Doğum ve Kapanış Anı

Kurucu ve yıkıcı metotları da sınıf dışında :: operatörüyle tanımlayabiliriz.

main.cpp
CTOR & DTOR 
#include <iostream>
using namespace std;

class Sensor {
public:
    string tip;

    Sensor(string sensorTipi); // Constructor imzası
    ~Sensor();                  // Destructor imzası
};

// Sınıf dışında :: ile tanımlamalar
Sensor::Sensor(string sensorTipi) {
    tip = sensorTipi;
    cout << "[ACILDI] " << tip << " sensoru aktif!" << endl;
}

Sensor::~Sensor() {
    cout << "[KAPANDI] " << tip << " guvenle kapatildi." << endl;
}

int main() {
    cout << "--- Program Basladi ---" << endl;
    Sensor s1("Lidar");
    Sensor s2("Sicaklik");
    cout << "--- Program Bitiyor ---" << endl;

    return 0; // Önce s2, sonra s1 için Destructor otomatik çalışır!
}

Kalıtım (Inheritance): Base & Derived Class

Ortak özellikleri bir Ana Sınıfta (Base Class) toplayıp yeni sınıflara miras bırakarak kod tekrarını önleriz.

🏛️ Base Class (Temel / Ata Sınıf)

Tüm alt türlerin sahip olduğu genel özellikleri barındırır.

Örnek: Arac sınıfı
• Özellik: hiz
• Metot: hizlan()

🚀 Derived Class (Türetilmiş / Alt Sınıf)

Ata sınıfın tüm mirasını alır ve üzerine kendine özgü yeni yetenekler ekler.

Örnek: Drone : public Arac
• Miras: hiz, hizlan()
• Yeni Özellik: irtifa, yuksel()

🔑 protected Burada Devreye Girer!

Ata sınıftaki bir değişken private ise miras alan sınıf bile ona erişemez. Ama protected yaparsanız dışarıya kapalı kalır, fakat türetilmiş sınıflar (Derived Class) doğrudan kullanabilir.

Konu 3 / Slayt 2

Kod Örneği: Sınıflar Arası Miras (:: ile)

Tek dosya içinde hem Arac hem Drone sınıflarını tanımlayıp gövdelerini :: operatörüyle yazıyoruz.

main.cpp
INHERITANCE 
#include <iostream>
using namespace std;

// 1. Base Class (Ana Sınıf)
class Arac {
protected:
    int hiz = 0; // Alt sınıflar erişebilir
public:
    void hizlan(int artis);
};

// 2. Derived Class (Arac sınıfından miras alır)
class Drone : public Arac {
public:
    int irtifa = 0;
    void yuksel(int metre);
};

// Metot gövdeleri (:: ile)
void Arac::hizlan(int artis) {
    hiz += artis;
    cout << "Guncel Hiz: " << hiz << " km/s" << endl;
}

void Drone::yuksel(int metre) {
    irtifa += metre;
    cout << "Irtifa: " << irtifa << " m | Yatay Hiz: " << hiz << endl;
}

int main() {
    Drone iha;
    iha.hizlan(40);  // Arac sınıfından gelen miras fonksiyon!
    iha.yuksel(100); // Drone sınıfının kendi fonksiyonu!

    return 0;
}
