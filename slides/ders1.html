While Döngüsü & Sonsuz Döngü (Infinite Loop)

Belirtilen koşul true olduğu sürece bloğu tekrarlar. Koşul en başta kontrol edilir.

while_syntax.cpp
//Donguler :
//--------- WHILE DONGUSU -------------
/*
while(condition){
...
...
...
(UNUTMA : gerekirse condition degeri guncellenmeli)
}
*/
int i = 0;
while (i <= 10) {
    cout << "iterasyon -" << i << endl;
    i++;
}
⚠️ Kritik Uyarı: Sonsuz Döngü (Infinite Loop)

Döngü bloğu içinde koşul değişkeni (i++) güncellenmezse koşul her zaman 0 <= 10 (yani true) kalır. Program sonsuz döngüye girer, CPU kilitlenir veya terminal durmaksızın çıktı üretir!

Konu 4 / Slayt 6

Akış Kesiciler (break / continue) & Kapsamlı Örnek

Break: Döngüyü tamamen bitirir. Continue: Alt satırları çalıştırmadan o anki adımı atlayıp döngüyü sürdürür.

break_continue_ornek.cpp
//BREAK VE CONT. DEYIMLERI : 
//Break = donguyu sonlandiriyor. altinda kalan kodlar calismaz.
//Continue = donguyu devam ettiriyor. altindakiler calistirilmadan.

// ORNEK : baslangic ve bitis degerleri kullanicidan alinir. Araliktaki tek sayilarin toplami bulunur.
int total = 0;
int m;
int baslangicDegeri;
int bitisDegeri;
int sinirDegeri;

cout << "Baslangic degeri : ";
cin >> baslangicDegeri;
cout << "Bitis degeri : ";
cin >> bitisDegeri;
cout << "Sinir degeri : ";
cin >> sinirDegeri;

for(m = baslangicDegeri; m < bitisDegeri; m++){
    if(m >= sinirDegeri){
        break;
    }
    if(m % 2 == 0){
        continue;
    }
    total += m;
    cout << m << endl;
}
cout << "Toplam : " << total << endl;
