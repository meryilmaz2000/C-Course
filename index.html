Ders İçi İnteraktif Quizler: "C++ Ne Yazar?"

Derslerde her konunun ardından ekrana yansıtılacak olan canlı tahmin mekanizması örneği.

quiz_01_division.cpp Hafta 1 Quiz 
#include <iostream>

int main() {
    int a = 7;
    int b = 2;
    float c = a / b;

    // Konsola tam olarak ne yazdırılır?
    std::cout << c << std::endl;
    return 0;
}

Tuzak: c değişkeni float olmasına rağmen a / b ifadesi iki tamsayı arasındadır.

İlk Derse Gelmeden Önce: Kurulum Rehberi

Derslerde vakit kaybetmemek için bilgisayarınıza derleyici ve editörü kurmanız önerilir.

Windows (MinGW-w64 / MSYS2)

GCC & G++ Derleyicisi Kurulumu

  1. VS Code'u resmi sitesinden indirin ve kurun.
  2. VS Code Eklentiler kısmından "C/C++" (Microsoft) ve "Code Runner" eklentilerini kurun.
  3. Derleyici için w64devkit veya MSYS2 ile GCC'yi edinin.
  4. MinGW'nin bin klasörünü Windows'un Sistem Ortam Değişkenleri (PATH) kısmına ekleyin.
  5. Terminalde kontrol edin:
    g++ --version

macOS & Linux (Clang / GCC)

Yerel Terminal Paketleri

macOS (Apple Clang):

Terminali açın ve Xcode komut satırı araçlarını yükleyin:

xcode-select --install
Ubuntu / Debian:
sudo apt update && sudo apt install build-essential gdb
Fedora / Arch:
sudo dnf groupinstall "Development Tools"
