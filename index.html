🛠️ Orwell Dev-C++ Kurulumu

C++ kodlarımızı yerel olarak derlemek için hafif ve MinGW/GCC ile paketli gelen Orwell Dev-C++ ortamını kullanacağız.

1
Aşağıdaki butona tıklayarak SourceForge üzerinden kurulum dosyasını indirin ve kurun.
2
Programı açıp File -> New -> Source File (Ctrl + N) ile boş bir kaynak dosyası oluşturun.
3
Sağdaki test kodunu editöre yapıştırıp F11 (Compile & Run) tuşuna basarak çalıştırın.
