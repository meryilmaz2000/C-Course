Geliştirme Ortamı: Dev-C++

Eğitim boyunca hafifliği, dahili GCC derleyicisi ve doğrudan kurulabilmesi sebebiyle Dev-C++ kullanacağız.

Dev-C++ Kurulum Adımları

Derslere gelmeden önce bilgisayarınızda derleyicinin hazır olması gerekmektedir.

  1. Embarcadero Dev-C++ (güncel TDM-GCC sürümü içeren paket) kurulum dosyasını indirin.
  2. Kurulum sırasında TDM-GCC bileşeninin seçili olduğundan emin olarak kurulumu tamamlayın.
  3. Programı açıp File -> New -> Source File yolunu izleyin.
  4. Konsol ekranında Türkçe karakterlerin ve modern C++ özelliklerinin sorunsuz çalışması için Tools -> Compiler Options altından -std=c++11 veya üstü bayrağı aktif edebilirsiniz.

İlk Test ve Derleme

Kurulumun başarılı olduğunu doğrulamak için aşağıdaki adımları deneyin:

  1. Yeni bir kaynak dosyası açıp içine cout << "Test"; içeren temel main fonksiyonunu yazın.
  2. Dosyayı .cpp uzantısıyla kaydedin (Örn: deneme.cpp).
  3. Klavyeden F11 tuşuna basarak (Compile & Run) kodun derlenip konsol penceresinin açıldığını doğrulayın.
  4. Herhangi bir derleme hatası alırsanız ders WhatsApp grubundan destek alabilirsiniz.

Sorularınız mı Var?

Kodlama esnasında takıldığınız yerleri veya derleyici kurulumuyla ilgili sorularınızı topluluk WhatsApp grubuna iletebilirsiniz.
